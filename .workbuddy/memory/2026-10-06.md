- 凭据管理器里 `git:https://github.com` 存的 PAT（gho_…）**已失效**，API 返回 401，无法用它建仓库；
  WorkBuddy 内置 GitHub 集成也是 403（integration 无建库权限）→ 建新仓库需用户在网页端手动建。
